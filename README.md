# Portfolio via Tailwind

A simple personal portfolio website built with HTML and Tailwind CSS.

## Features

- Responsive portfolio layout
- Modern styling with Tailwind CSS
- Lightweight static site setup
- Easy local development and production build workflow

## Project Structure

- `index.html` — main page markup
- `src/input.css` — Tailwind source stylesheet
- `src/output.css` — compiled CSS output
- `src/images/` — project images and assets

## Getting Started

1. Install the dependencies:
   ```bash
   npm install
   ```

2. Start the Tailwind watch process:
   ```bash
   npm run dev
   ```

3. Open the project in your browser and view the page.

## Build for Production

To generate the final CSS bundle:

```bash
npm run build
```

## Notes

This project uses the Tailwind CLI to compile styles from `src/input.css` into `src/output.css`.
